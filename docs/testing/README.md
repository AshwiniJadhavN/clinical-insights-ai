# AI Assisted Integration Testing

This directory stores advisory integration-testing artifacts produced by the Testing AI module.

- Generated Markdown reports are written to `docs/testing/ai_assisted_integration_report.md`.
- Generated Mermaid graph artifacts are written to `docs/testing/integration_test_graph.mmd`.
- Generated pytest drafts are written to `tests/generated/` and require human review before use.
- CI uploads the latest report and any failure-analysis JSON as build artifacts.
